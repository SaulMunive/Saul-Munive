### 🚧 Proyectos destacados

#### 🔹 [TransAndino Express — Azure Data Engineering](https://github.com/SaulMunive/smunive-tp-ade3)
Pipeline end-to-end de datos de logística sobre **Azure**, con arquitectura Medallion completa (raw → landing → bronze → silver → gold).
- **Stack:** Azure Data Lake Storage Gen2, Azure Data Factory, Azure Databricks (PySpark/SQL), Unity Catalog, Key Vault, Microsoft Fabric (Lakehouse + Direct Lake) y Power BI.
- Pipeline orquestado en ADF con Copy Activities parametrizados, notebooks de transformación, deduplicación con Window Functions, `MERGE INTO` para cargas incrementales y Delta Time Travel.
- Modelo semántico y reporte en Power BI conectado vía Direct Lake sobre Fabric.

#### 🔹 [RetailFast — Monitoreo de transacciones en tiempo real (GCP)](https://github.com/SaulMunive)
Sistema de streaming de eventos para detección de transacciones en tiempo real usando **Google Cloud**.
- **Stack:** Pub/Sub, BigQuery, Python.
- Publicación de eventos vía Pub/Sub con suscripción directa hacia BigQuery, sin intermediarios, siguiendo patrones de ingesta orientados a producción.

#### 🔹 [Agente de Análisis Conversacional con BigQuery](https://github.com/SaulMunive/agente-analytics-google-merchandise)
Agente conversacional que permite consultar datos de analítica web en lenguaje natural.
- **Stack:** BigQuery (dataset público de Google Merchandise Store), Cloud Run Functions, Gemini Data Analytics.
- Backend desplegado como función serverless en Cloud Run y frontend propio con visualizaciones dinámicas (Vega).
- Demo publicada vía **GitHub Pages**: [ver demo](https://saulmunive.github.io/agente-analytics-google-merchandise/)
